# 台風メーカー / game-taifu

日本地図に台風の進路を一筆書きして、架空の被害スコアを競うブラウザゲームです。暖かい海で勢力を育て、山越えで構造が崩れる前に都市を目指します。ポップな見た目の、物理シミュレーション風ゲーム Version 0.1 です。

**実際の気象予測・防災判断には使用できません。** 都市の資産量・被害スコアはゲーム用の仮の値です。

## 起動方法

Node.js **22.12 以降、または 24** と npm を使用します。リポジトリを取得した後、以下を実行してください。

```sh
npm ci
npm run dev
```

ターミナルに表示される URL をブラウザで開きます。同じネットワークのスマートフォンで試す場合は、開発 PC の IP アドレスと表示されたポートを使用してください。

```sh
npm test          # シミュレーションの自動テスト
npm run build     # TypeScript の型検査と本番ビルド
npm run preview   # dist/ の内容をローカル確認
```

サーバーの実装や API キーは不要です。実行時の外部ライブラリは使用していません。

## 遊び方

1. 南の海にいる台風から、マウスまたは指を押したまま進路を描きます。線の交差や、同じ場所の再通過も可能です。
2. マウスまたは指を離し、**「台風、出発！」** を押します。離した後も線の終点から続きを描けます。**「描き直す」** で最初から引き直し、**「おまかせ進路」** でサンプルの進路を選べます。
3. 海・平地・山地で変化する勢力と構造の安定度を見ながら、都市の被害スコアを狙います。一時停止と 1 / 2 / 4 倍速を利用できます。
4. 終点への到達、勢力の衰退、構造の崩壊、季節による終了のいずれかで結果が表示されます。**「新しい進路で挑戦」** または **「同じ進路でもう一度」** で再挑戦すると、日付と各都市の資産が初期化されます。

日付は毎回 **9 月 1 日** から始まります。秋が深まると海上でも発達しにくくなり、11 月は衰退しやすく、12 月 1 日までに台風としての活動を終えます。進路の長さや総移動時間には直接の上限を設けていません。

スマートフォンでは地図上の操作中にページのスクロールが入らないようにしています。地図以外の部分から画面をスクロールできます。描画操作にはマウス・タッチ・ペンの Pointer Events を使用し、ボタンはキーボード操作に対応しています。一筆書きが難しい場合も、**「おまかせ進路」** でプレイできます。

自己ベストは、このブラウザの `localStorage` に保存します。ブラウザのサイトデータを削除すると記録も消えます。保存が制限された環境でもゲームは遊べます。**「遊び方」** を開くか、別のタブに切り替えると自動で一時停止します。

## シミュレーションとスコア

- **勢力:** 暖かい海上で回復し、陸上で低下します。山地では平地よりも大きく低下します。
- **構造の安定度:** 上陸や山越えで低下し、海上でゆっくり回復します。安定度によって最大勢力も制限され、崩壊すると終了します。
- **季節:** 移動とともにゲーム内の日付が進みます。季節で海の発達しやすさが変わり、晩秋には海上でも衰退します。長寿の台風は回復できる構造の上限も下がります。
- **被害:** 都市ごとに有限の資産を持ち、台風の勢力と都市からの距離による被害を累積します。過去に受けた最大の被害を超えた分だけ加算するため、同じ地点に滞在したり、同じ勢力で往復したりしても無限に加点されません。

計算は固定の時間刻みで行い、描画のフレームレートや再生速度による結果のずれを抑えています。数値は初期バランスです。遊びながら調整してください。

## 構成と調整箇所

| ファイル | 役割 |
| --- | --- |
| `src/config.ts` | シミュレーションの調整パラメータと都市の重み |
| `src/data/map.ts` | 手描きの海岸線・山地データ |
| `src/data/cities.ts` | 都市の位置と仮の資産データ |
| `src/geo.ts` | 海・平地・山地の判定と座標処理 |
| `src/simulation.ts` | 台風の状態遷移、移動、季節、被害計算 |
| `src/renderer.ts` | HTML Canvas による地図・台風・進路・演出の描画 |
| `src/main.ts` | 入力、UI、ゲームループ |

勢力の増減率、構造の劣化・回復率、季節の進行速度、移動速度、被害範囲・倍率、都市ごとの重みは `src/config.ts` に集約しています。都市の位置や対象地域の追加は `src/data/cities.ts`、海岸線・山地の変更は `src/data/map.ts` を編集してください。データとシミュレーションを分離しているため、将来、実際の人口密度や土地利用データを地域ごとの資産データに変換して差し替える構成です。

主な設定は以下のとおりです。増減率は 1 シミュレーション秒あたりの基準値で、海上では季節による補正が加わります。

| 設定 | 初期値・意味 |
| --- | --- |
| `initialStrength` / `initialStability` | 初期勢力 76 / 初期安定度 90 |
| `movementSpeed` / `daysPerSecond` | 毎秒 18 地図単位 / 毎秒 1.2 日進行 |
| `fixedStepSeconds` | 計算刻み 0.02 秒 |
| `oceanStrengthRecovery` / `oceanStabilityRecovery` | 暖海での回復基準 4 / 0.35 |
| `landStrengthDecay` / `landStabilityDecay` | 平地での低下 4.6 / 2.8 |
| `mountainStrengthDecay` / `mountainStabilityDecay` | 山地での低下 9 / 6.5 |
| `coldSeaStrengthDecay` / `coldSeaStabilityDecay` | 冷たい海による衰退基準 5 / 0.8 |
| `stabilityCapBase` / `stabilityCapFactor` | 最大勢力 = 25 + 安定度 × 0.85（上限 100） |
| `lifetimeCapacityLossPerDay` | 回復できる安定度の上限を 1 日ごとに 0.28 低下 |
| `minimumStrength` / `minimumStability` | 勢力 5 以下で消滅 / 安定度 13 以下で温帯低気圧化 |
| `winterDay` | 開始から 91 日でシーズン終了（12 月 1 日） |
| `cityExposureExponent` | 被害に対する勢力の指数 2 |
| `CITY_RADIUS` | 都市の影響半径 26 地図単位 |
| `CITY_WEIGHTS` | 都市別の最大資産。例: 東京 120,000 / 大阪 85,000 / 名古屋 65,000 |

`npm test` では、海上回復、山地の追加消耗、構造による勢力制限、冬の終了、再通過の得点上限、経路の交差・終点到達、フレーム間隔による結果の一致などを確認します。

## GitHub Pages への公開

GitHub Actions の公開用ワークフローを `.github/workflows/pages.yml` に用意しています。

1. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. 実装を `main` ブランチに push するか、**Actions → Deploy to GitHub Pages → Run workflow** を実行します。
3. ワークフローが `npm ci`、`npm test`、`npm run build` を実行し、成功すると `dist/` を Pages に公開します。公開先は Actions の `github-pages` 環境に表示されます。

このリポジトリの通常の公開先は `https://0052-g.github.io/game-taifu/` です。実際の公開には上記の設定とワークフローの成功が必要です。デフォルトブランチを変更した場合はワークフローの `branches` も変更してください。

Vite の `base` を `./` に設定し、アセットを相対パスで参照するため、GitHub Pages のリポジトリ配下でも動作します。他の静的ホスティングでは `dist/` の内容を配信できます。

## データと未実装の要素

地図・山地はこのゲーム向けに作成した簡略図です。外部の地理・人口・建物データは使用していません。都市の位置は概略で、資産の重みは架空です。フォントは端末の標準フォントを使用し、ゲーム実行時に外部サービスへの通信は行いません。

Version 0.1 には、実際の人口・地形メッシュ、オンラインランキング、音声、高度な気象モデルやエフェクトは含まれません。
