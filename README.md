# 台風メーカー / game-taifu

日本地図に台風の進路を一筆書きして、架空の被害スコアを競うブラウザゲームです。暖かい海で勢力を育て、山越えで構造が崩れる前に人口の多い地域を目指します。ポップな見た目の、物理シミュレーション風ゲーム Version 0.2.1 です。

**実際の気象予測・防災判断には使用できません。** 人口・標高は公開データに基づきますが、資産と被害スコアはゲーム用の値で、実際の建物資産・被害額・人的被害を表しません。

## Version 0.2.1 の描画軽量化

- 被害表示は変更のあったメッシュ範囲だけを描き直し、海岸線の切り抜きマスクを再利用します。
- 白い羽雲の台風と都市名などの静的な表示を画像としてキャッシュします。
- 地図キャッシュを表示サイズに合わせ、描画解像度を DPR 2 までに抑えます。人口レイヤーの背景は必要になったときに作成します。
- 勢力・日付・得点などの画面表示で、同じ文字や数値の再書き込みを減らします。

人口・標高データ、得点計算、寿命、再生速度は 0.2.0 と同じです。人口メッシュ版の既存の自己ベストも引き継ぎます。

描画の確認には、スマートフォン相当の画面幅や高解像度表示、ブラウザの CPU 低速化を使えます。レイヤー切り替え、被害表示、再挑戦、画面サイズ変更を試し、同じシミュレーション状態の画素を比較してキャッシュ更新のずれを確認します。

## Version 0.2.0 の変更

主要都市の仮の重みを、2020 年国勢調査の人口を約 5km メッシュへ集計したデータに置き換えました。都市ラベルがない場所でも人口メッシュに応じて得点できます。地形は国土地理院の DEM10B 由来の標高、海岸線は Natural Earth 5.1.2 の地理データを使用します。人口・地形レイヤーの切り替えと、出典の確認にも対応しています。

人口メッシュは全国合計 **126,146,099 人、13,799 セル** を収録しています。集計範囲は東経 122～154 度・北緯 20～47 度ですが、ゲーム画面は東経 122～148 度・北緯 24～47 度です。南鳥島など画面外の地域もデータに含まれるため、全国の全セルで遊べることを意味しません。

### 従来版から引き継いだ調整

0.1.1 で標準の移動を旧 4 倍速相当にし、日付の進行と陸上・山地の消耗を緩めました。0.1.2 では初期勢力を控えめにし、暖かい海で構造を立て直しやすくしました。有限の資産を再通過で少しずつ減らすルールと、顔のある白い羽根雲の台風を引き継いでいます。×1 / ×2 / ×4 は現在の標準速度を基準にした倍率です。

## 起動方法

Node.js **22.12 以降、または 24** と npm を使用します。リポジトリを取得した後、以下を実行してください。

```sh
npm ci
npm run dev
```

ターミナルに表示される URL をブラウザで開きます。同じネットワークのスマートフォンで試す場合は、開発 PC の IP アドレスと表示されたポートを使用してください。

```sh
npm test          # シミュレーションの自動テスト
npm run build     # TypeScript の型検査と本番ビルド
npm run preview   # dist/ の内容をローカル確認
```

サーバーの実装や API キーは不要です。実行時の外部ライブラリは使用していません。

## 遊び方

1. 南の海にいる台風から、マウスまたは指を押したまま進路を描きます。線の交差や、同じ場所の再通過も可能です。
2. マウスまたは指を離し、**「台風、出発！」** を押します。離した後も線の終点から続きを描けます。**「描き直す」** で最初から引き直し、**「おまかせ進路」** では、初回の上陸から海上回復を挟み、再上陸するサンプルを選べます。
3. 海・平地・山地で変化する勢力と構造の安定度を見ながら、都市の被害スコアを狙います。一時停止と ×1 / ×2 / ×4 を利用できます。倍率を上げると、移動・日付・勢力変化が同じ割合で速く進みます。
4. 終点への到達、勢力の衰退、構造の崩壊、季節による終了のいずれかで結果が表示されます。**「新しい進路で挑戦」** または **「同じ進路でもう一度」** で再挑戦すると、日付と各人口メッシュの資産が初期化されます。

地図上の **「人口」** で人口密度を、**「地形」** で海・平地・山地を確認できます。地図下には台風の現在メッシュの人口・平均標高を表示し、**「データ出典」** から取得元と制限を確認できます。

日付は毎回 **9 月 1 日** から始まります。秋が深まると海上でも発達しにくくなり、11 月は衰退しやすく、12 月 1 日までに台風としての活動を終えます。進路の長さや総移動時間には直接の上限を設けていません。

スマートフォンでは地図上の操作中にページのスクロールが入らないようにしています。地図以外の部分から画面をスクロールできます。描画操作にはマウス・タッチ・ペンの Pointer Events を使用し、ボタンはキーボード操作に対応しています。一筆書きが難しい場合も、**「おまかせ進路」** でプレイできます。

自己ベストは、このブラウザの `localStorage` に保存します。人口メッシュ版は従来版と別の記録です。ブラウザのサイトデータを削除すると記録も消えます。保存が制限された環境でもゲームは遊べます。**「遊び方」** や **「データ出典」** を開くか、別のタブに切り替えると自動で一時停止します。

## シミュレーションとスコア

- **勢力:** 最初は控えめな勢力から始まり、暖かい海上で少しずつ回復し、陸上で低下します。山地では平地よりも大きく低下します。
- **構造の安定度:** 上陸や山越えで低下し、暖かい海上で回復します。海へ戻って立て直せますが、経過日数によって回復できる構造の上限は下がります。安定度によって最大勢力も制限され、崩壊すると終了します。
- **季節:** 移動とともにゲーム内の日付が進みます。季節で海の発達しやすさが変わり、晩秋には海上でも衰退します。長寿の台風は回復できる構造の上限も下がります。
- **地形:** 海陸は海岸線データで判定し、陸上メッシュの平均標高が 500m 以上、または起伏（最高－最低）が 300m 以上なら山地と扱います。標高が欠損した陸地は、欠損を示したうえで平地扱いにします。
- **被害:** 人口メッシュごとに `人口 × 0.005pt` の有限の架空資産を持ち、台風の勢力とメッシュ中心からの距離に応じて被害を累積します。同じ通過中は、その通過での最大影響度を更新した分だけ加算します。十分離れて再訪すると、残り資産を対象に新しい被害が出ます。資産が減るほど、同じ条件での再訪時の得点は小さくなります。資産は時間では回復しません。

同じ地点に居続けても、滞在時間による加点はありません。メッシュごとの計算式は `通過開始時の残り資産 × 0.5 × その通過での最大影響度` です。風の影響半径は 22 地図単位で、その 1.35 倍より離れると通過終了です。入り直すと新しい通過として扱い、以前より弱い勢力でも残り資産に応じて加点します。都市名の資産表示は地図上で最寄りの都市ラベルにまとめた集計で、行政区域の人口・資産ではありません。都市ラベルが重なっても同じ人口を二重に加点しません。

計算は固定の時間刻みで行い、描画のフレームレートや再生速度による結果のずれを抑えています。数値は初期バランスです。遊びながら調整してください。

## 構成と調整箇所

| ファイル | 役割 |
| --- | --- |
| `src/config.ts` | シミュレーション、人口から資産への換算、地形分類の調整 |
| `src/data/map.ts` | 地図座標・海岸線 |
| `src/data/mesh.ts` | 人口・標高メッシュの読み込みと近傍検索 |
| `src/data/japan-mesh.json` / `coastline.json` | 再生成可能な同梱データ |
| `src/data/city-locations.ts` | 都市ラベルの名前と位置 |
| `src/data/cities.ts` | 人口メッシュの表示用集計を都市ラベルに対応付け |
| `src/geo.ts` | 海・平地・山地の判定と座標処理 |
| `src/simulation.ts` | 台風の状態遷移、移動、季節、被害計算 |
| `src/renderer.ts` | HTML Canvas による地図・台風・進路・演出の描画 |
| `src/main.ts` | 入力、UI、ゲームループ |
| `scripts/` / `data-sources/` | 元データの取得・加工スクリプトと出典・ハッシュの記録 |

勢力・構造・季節・移動・被害のパラメータは `src/config.ts` に集約しています。人口・標高・海岸線の取得元、加工方法、再生成コマンドと品質確認は [データ資料](data-sources/README.md) を参照してください。通常の起動やビルドでは元データの再取得は不要です。

主な設定は以下のとおりです。増減率は 1 シミュレーション秒あたりの基準値で、海上では季節による補正が加わります。

| 設定 | 初期値・意味 |
| --- | --- |
| `initialStrength` / `initialStability` | 初期勢力 58 / 初期安定度 90 |
| `movementSpeed` / `daysPerSecond` | 毎秒 72 地図単位 / 毎秒 0.6 日進行（×1 時） |
| `fixedStepSeconds` | 計算刻み 0.02 秒 |
| `oceanStrengthRecovery` / `oceanStabilityRecovery` | 暖海での回復基準 3.2 / 1.15 |
| `landStrengthDecay` / `landStabilityDecay` | 平地での低下 2.6 / 1.35 |
| `mountainStrengthDecay` / `mountainStabilityDecay` | 山地での低下 5.2 / 3.2 |
| `coldSeaStrengthDecay` / `coldSeaStabilityDecay` | 冷たい海による衰退基準 5 / 0.8 |
| `stabilityCapBase` / `stabilityCapFactor` | 最大勢力 = 25 + 安定度 × 0.85（上限 100） |
| `lifetimeCapacityLossPerDay` | 回復できる安定度の上限を 1 日ごとに 0.28 低下 |
| `minimumStrength` / `minimumStability` | 勢力 5 以下で消滅 / 安定度 13 以下で温帯低気圧化 |
| `winterDay` | 開始から 91 日でシーズン終了（12 月 1 日） |
| `cityExposureExponent` | 被害に対する勢力の指数 2 |
| `meshAssetPointsPerPerson` | 人口 1 人あたり 0.005pt のゲーム用資産（通貨ではない） |
| `meshWindRadius` | 人口メッシュへの影響半径 22 地図単位 |
| `meshPassDamageFraction` | 1 回の通過で被害にできる割合 0.5（通過開始時の残り資産が基準） |
| `meshVisitExitMargin` | 通過終了の判定に影響半径の 35% を追加（半径 × 1.35 より外） |
| `terrainMountainElevationM` / `terrainMountainReliefM` | 山地とする平均標高 500m / 起伏 300m の基準（いずれかを満たす） |

`npm test` では、海上回復、山地の追加消耗、構造による勢力制限、冬の終了、通過ごとの被害と有限の資産、経路の交差・終点到達、フレーム間隔による結果の一致などを確認します。

## GitHub Pages への公開

GitHub Actions の公開用ワークフローを `.github/workflows/pages.yml` に用意しています。

1. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. 実装を `main` ブランチに push するか、**Actions → Deploy to GitHub Pages → Run workflow** を実行します。
3. ワークフローが `npm ci`、`npm test`、`npm run build` を実行し、成功すると `dist/` を Pages に公開します。公開先は Actions の `github-pages` 環境に表示されます。

このリポジトリの通常の公開先は `https://0052-g.github.io/game-taifu/` です。実際の公開には上記の設定とワークフローの成功が必要です。デフォルトブランチを変更した場合はワークフローの `branches` も変更してください。

Vite の `base` を `./` に設定し、アセットを相対パスで参照するため、GitHub Pages のリポジトリ配下でも動作します。他の静的ホスティングでは `dist/` の内容を配信できます。

## データの出典と制限

人口は「令和2年国勢調査に関する地域メッシュ統計」（総務省統計局、地理院地図で提供）を加工し、約 5km に集計しています。標高は地理院タイル（標高タイル・基盤地図情報数値標高モデル）由来の公開ミラーを加工しています。いずれも台風メーカー開発者によるゲーム用の加工で、各提供機関が作成した被害データではありません。[e-Stat 利用規約](https://www.e-stat.go.jp/terms-of-use)、[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)、[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)に従って出典を表示します。

海岸線は [Natural Earth 5.1.2](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2) の 1:10,000,000 の国別ポリゴンを加工しています。「10m」は縮尺の 10 million を指し、10 メートル精度ではありません。[Natural Earth の利用条件](https://www.naturalearthdata.com/about/terms-of-use/)は Public Domain です。

人口の元測地系が JGD2000／JGD2011 のどちらかはミラーに記載がなく、断定していません。標高は約 10m の元 DEM を直接同梱したものではなく、約 216～287m の z9 ピクセルを約 5km に集約したものです。最高標高は取得ピクセル内の最大値で、山頂の真の高さではありません。元ミラーの海・欠損の埋め値と本当の標高 0m は完全には区別できないため、海岸線マスクを併用し、全サンプルが 0 のセルや欠損を識別して保持しています。細い島・海岸線には縮尺による誤差があります。詳しい取得先と制限は [データ資料](data-sources/README.md) にまとめています。

フォントは端末の標準フォントを使用します。ゲームは加工済みデータを同梱した静的アプリで、プレイ時に人口・標高 API を呼び出しません。実際の建物・土地利用データ、オンラインランキング、音声、高度な気象モデルやエフェクトは未実装です。
